# Copilot Instructions

## Stack

- Tanstack Start
- SolidJS
- TypeScript

## Architecture

- Route-based structure from Tanstack start
- Component should be small and composable
- Server functions handled via TanStack conventions

## Rules

- Do not introduce React patterns
- Prefer SolidJS primitives (createSignal, createEffect)
- Avoid unnecessary abstractions early

## When implementing features

- Always propose a plan first
- List files to modify
- Keep changes minimal and scoped
